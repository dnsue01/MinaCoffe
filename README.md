# MINA Specialty Coffee

Carta digital de una cafetería de especialidad en Madrid. Reúne los platos destacados, bebidas, tostadas, pinsas, repostería y opciones de café de origen.

[Visitar la web](https://dnsue01.github.io/MinaCoffe/)

Carta digital de MINA Specialty Coffee (Calle Príncipe de Vergara 109, Madrid).

Web estática en un solo `index.html`, publicada con GitHub Pages. Logos vectorizados en `assets/`.
